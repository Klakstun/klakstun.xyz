# [klakstun.xyz](klakstun.xyz) | 一次性文件传输系统

一个极简、免注册的阅后即焚文件分享工具。

## 核心特性

- **阅后即焚**：文件仅允许下载一次，下载完成后立即从服务器物理销毁。
- **极简无感**：无需注册，上传后生成一次性下载密钥，凭密钥取件。
- **自我净化**：内置定时清扫机制，自动清理过期或废弃的文件，不留任何冗余。
- **多语言支持**：内置 6 种语言的无缝切换。
