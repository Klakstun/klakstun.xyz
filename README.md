# Tools

一个在浏览器里跑的工具集。目前包含一个工具：MIDI 文本编辑器。

## 项目结构

Tools 是一个工具集项目。它的定位不是一个单独的工具，而是一个能容纳多个工具的容器。每个工具独立运行，互不干扰。

目前包含：

- **MIDI 文本编辑器**：用文本写音符，支持纯律音阶，能播放。

## MIDI 文本编辑器

这是目前 Tools 里唯一完整落地的功能。

它的做法很单一：让你用文本的方式，写出一串音符，然后播放它。

每个音符写成一行，格式是：

    时值, 音高, 大小, 编号

比如 `1/1, 3/2, 10, 05`，就是一个音高为纯五度的音符。

这套格式从第一个版本到现在，没有变过。界面换了好几代，数据格式一直稳定。

### 核心特性

- **纯律支持**：不按十二平均律走。音高用分数表示，比如 `3/2` 是纯五度，`5/4` 是大三度。基准频率可调，默认 261.6 Hz。
- **文本编辑**：音符不是用鼠标画的，是一行一行写出来的。
- **亮暗双模式**：两套配色，切换时平滑过渡。
- **多主题配色**：默认、海洋、森林、日落、薰衣草、樱花。
- **中英双语**。
- **桌面布局**：右侧信息面板显示当前选中音符的详细参数。

### 版本历史

这个工具从 1.0 迭代到 7.0。

| 版本 | 主要变化 |
|---|---|
| v1 | 单页，纯律音阶播放 |
| v2 | 加了和弦语法，加了导出入口 |
| v3 | SSTV 文本转音频并入，顶部导航成型 |
| v4 | 功能收进左侧，模块化拆分 |
| v5 | 转为 Material Design 3，暗色主题，中英双语 |
| v6 | 引入主题系统，主题与主逻辑混杂 |
| v6.1 | 主题系统拆分为独立文件，修复 v6 的问题 |
| v6.2 | 修复播放模块，兼容旧逻辑 |
| v7 | 转为粘土拟态，加入桌面版布局 |

v1 到 v7 的完整源码，保存在 `Midi Editor History Version Archive` 目录下。

## 技术形态

纯前端。没有后端，没有数据库，没有服务器逻辑。

托管在 Cloudflare Pages 上，源码在 GitHub。

主题系统是拆开的：CSS 变量定义颜色，JS 负责切换，布局不随主题变动。
